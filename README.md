# Assignment5-React-Controlled-Form

React + Vite project configured for GitHub Pages.

## Deployment
1. Upload all files and folders in this project to the root of its own GitHub repository. Include the hidden `.github/workflows/deploy.yml` file.
2. In repository Settings → Pages, set Source to **GitHub Actions**.
3. Open Actions and wait for the workflow to finish with a green checkmark.

The workflow runs `npm run build` and publishes the generated `dist` folder.

## Run locally
Run `npm install`, then `npm run dev`.
